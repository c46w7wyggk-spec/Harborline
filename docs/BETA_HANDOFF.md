# Harborline — Private Beta Handoff

Status, evidence and remaining blockers are in **[BETA_STATUS.md](BETA_STATUS.md)**. This file is the how-to.

## 1. What's in the beta

One compact harbor district (~1.6 km², ~730 parts, generated by code at server start):

| Place | What you do there |
|---|---|
| **Hub plaza** (spawn, safe) | Job Board, Car Lot, Noodle Stand, fountain, clock tower |
| **Parcel Depot** (west) | Courier Run pickup |
| 10 shop **addresses** | Courier Run drop-offs (blue mailboxes with name labels) |
| **Harbor Boulevard** + start arch | Harbor Sprint start/finish, loop around the district |
| **Old Mint Museum** (north-east) | Vault Job: crack the prop vault in the courtyard |
| **Dockside Warehouse** (south-west) | Vault Job drop-off |
| Lighthouse island, Ferris wheel park | Landmarks for orientation |

Jobs (server-authoritative, 1–4 minutes each): **Courier Run** (Rep 1, on foot or driving), **Harbor Sprint**
(Rep 1, needs a car, gold/silver/bronze medals), **Vault Job** (Rep 3, 10-minute cooldown, non-graphic: no weapons,
no NPCs, no injuries). Progression: cash + Rep, 5 cars (Pebble free → Nightjar $95k), Noodle Stand business with 4
levels that earns while you play. Numbers: `src/shared/Config/*.luau`; design rationale: `docs/ECONOMY.md`.

## 2. Controls

| Action | Keyboard / mouse | Gamepad | Touch |
|---|---|---|---|
| Move / drive | WASD or arrows | Left stick (+ RT/LT in a car) | Thumbstick |
| Jump / exit car | Space | A | Jump button |
| Interact (Job Board, Car Lot, Noodle Stand, Drive) | E | X | Tap the prompt |
| Phone (jobs, garage, car lot, business) | J or the PHONE button | Y | PHONE button (top-right) |
| Close phone | Backspace / X button | B | X button |
| Cancel job | X on the objective panel | (open phone → Cancel job) | X on the objective panel |

## 3. Toolchain and automated checks (no Studio needed)

```bash
# one-time (Rust toolchain required): ~5 min
cargo install --locked rojo stylua lune
# every change
./scripts/check.sh
```
`check.sh` runs: StyLua format check, Luau compile of every file, **33 unit tests** (economy, schema
sanitising, validation, rate limiting, all three job state machines, anti-cheat floors), a **smoke test** that runs
the real WorldBuilder, all 5 vehicle builds and the whole client UI against Roblox's reflection database (catches
wrong class/property/enum names), geometry checks (no job point inside a building), and the `rojo build`.

## 4. Open it in Roblox Studio (owner, ~10 minutes)

> Claude could not run Studio. Everything in this section must be done by you.

1. Install **Roblox Studio** (not the same app as the Roblox player).
2. Get the place file: either run `rojo build -o Harborline.rbxlx` or download `build/Harborline.rbxlx` from the PR
   artifacts, then double-click it to open in Studio. For live editing instead: install the Rojo Studio plugin,
   run `rojo serve`, and click **Connect** in the plugin.
3. **Create two separate experiences** (data never mixes):
   - **Harborline DEV**: File → Publish to Roblox → *new* experience. Then **File → Experience Settings → Security →
     Enable Studio Access to API Services = ON**. Use this one for Studio testing with saves.
   - **Harborline BETA**: publish the same place as a *second, new* experience. Leave Studio API access **OFF**.
     Testers play this one. Both stay **Private** (the default). Don't enable "beta mode" (it makes the game searchable).
   - Even inside one experience, Studio sessions use a separate store name (`HarborlinePlayers_v1_STUDIO`).
   - If Studio API access is off, the game still runs: it shows "STUDIO TEST MODE - progress not saved".
4. Press **Play** (F5) and look at the Output window. You should see
   `[World] Harborline built: 731 parts` and `[Harborline] server ready`.

## 6. Exploit probes (client Command Bar during Play)

```lua
local R = game.ReplicatedStorage.Remotes.Request
print(R:InvokeServer("StartJob", {}))            -- table arg -> false "Invalid request."
print(R:InvokeServer("StartJob", 0/0))           -- NaN -> false
print(R:InvokeServer("GiveCash", "999999"))      -- unknown action -> false
print(R:InvokeServer("BuyVehicle", "nightjar"))  -- far from Car Lot / no cash -> false
for i = 1, 40 do R:InvokeServer("GetState") end  -- rate limit -> "Slow down a little!"
-- teleport during a job (should cancel the job and log [Anticheat])
game.Players.LocalPlayer.Character:PivotTo(CFrame.new(-700, 5, 500))
```

## 7. Data setup and admin notes

- Store: `HarborlinePlayers_v1` (live) / `HarborlinePlayers_v1_STUDIO` (Studio). Key: `p_<UserId>`.
  Record `{ data = profile (schema 1), lock = {server, t}, savedAt }`.
- Session lock: a server only writes a profile while it holds the lock; locks go stale after 150 s (crashed server).
  A player hopping servers within that window waits up to ~30 s or gets a "rejoin in a minute" kick, never a rollback.
- Saves: autosave every 60 s, urgent save ~8 s after payouts/purchases, save + unlock on leave, parallel save on shutdown.
- Diagnostics: Output lines starting `[Data]`, `[Anticheat]`, `[Payout]`, `[Net]` (user ids only, no names).
- Give yourself Rep for testing (DEV only, server Command Bar):
  `require(game.ServerScriptService.Server.Services.DataService).profile(game.Players:GetPlayers()[1]).rep = 300`
- Wipe a tester: Creator Dashboard → DEV experience → Data Stores manager, or `RemoveAsync("p_<id>")`.

## 8. Inviting private beta testers (owner only — Claude must not do this)

Follow `docs/COMPLIANCE.md` §(b) for current menu names. Short version:
1. **Complete the Maturity & Compliance questionnaire** for the BETA experience (Creator Dashboard → experience →
   Audience → Maturity & Compliance). Answer for the actual game: stylized non-graphic "heist" theme (fictional
   vault robbery, no weapons/blood), no gambling, no romance, no real brands, no paid items, chat = default Roblox chat.
2. Keep **Privacy = Private**. Do not enable beta mode or public access.
3. Recommended: move the experience to a **group** you own, create a **Tester** role with only "Playtest experiences"
   (no Edit, no Data Stores permissions), and add testers to it. Small alternative: Studio → Collaborate → add user
   with **Play** permission, or File → Invite early testers (max 10).
4. Send testers the experience link + `docs/FEEDBACK.md` questions.
5. Never spend Robux, enable paid access, or turn on monetization for the beta.
